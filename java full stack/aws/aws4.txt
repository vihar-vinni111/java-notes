Steps to interact with MySQL Database in RDS service 
====================================================
step1:
------
	Launch eclipse IDE.

step2:
------
	Create a java project i.e AWSProj.

step3:
------
	Add "mysql-connector.jar" file in project build path.


step4:
------
	Create a MySQL database in RDS service.
	
step5:
-------
	Create a "com.rt.www" package inside "AWSProj/src" folder.

step6:
----
	Create a SelectApp.java file inside "com.rt.www" package.

SelectApp.java
--------------
package com.rt.www;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.Statement;

public class SelectApp 
{
	public static void main(String[] args) 
	{
		final String DRIVER="com.mysql.cj.jdbc.Driver";
		final String URL="jdbc:mysql://database-1.c30c66ia0at5.us-east-1.rds.amazonaws.com:3306/aws_schema";
		final String USERNAME="admin";
		final String PASSWORD="adminadmin";
		final String QUERY = "select * from student";
		
		Connection con = null;
		Statement st = null;
		ResultSet rs = null;
		try
		{
			Class.forName(DRIVER);
			con = DriverManager.getConnection(URL,USERNAME,PASSWORD);
			st = con.createStatement();
			rs = st.executeQuery(QUERY);
			while(rs.next())
			{
				System.out.println(rs.getInt(1)+" "+rs.getString(2)+" "+rs.getString(3));
			}
			rs.close();
			st.close();
			con.close();
		}
		catch(Exception e)
		{
			e.printStackTrace();
		}
	}
}

step7:
------
	Launch mysql workbench and connect with cloud database.

step8:
-----
	Create and use schema in mysql database.
	ex:
		create schema aws_schema;
		use aws_schema;

step9:
------
	Create a Student table with records.

	ex:
		create table student(sno int(3), sname varchar(10), sadd varchar(12));
		insert into student values(101,'Alan','Florida');
		insert into student values(102,'Jose','Texas');	
		insert into student values(103,'Mark','Dellas');
		commit;

step10:
------
	Run JDBC application.


step11:
------
	Terminate the database.

step12:
------
	Delete the snapshot of database.



Elastic BeanStalk
==================
AWS Elastic Beanstalk is an AWS-managed service for web applications.

Elastic Beanstalk is a Platform As A Service (PAAS) as it allows users to directly use a pre-configured server for their applications.

First, create an application and select an environment, configure the environment, and deploy the application.



Steps to deploy web application in a cloud server 
================================================
step1:
------
	Launch eclipse IDE by choosing workspace location.

step2
-----
	Create a dynamic web project i.e MyAppProj.
	
Deployment Directory Structure 
------------------------------
MyAppProj
|
|---Java Resources
|
|---WebContent
	|
	|---index.jsp
	|---WEB-INF
		|
		|------web.xml 
		|------lib
			|
			|---servlet-api.jar
Note:
-----
In above application we need to add "servlet-api.jar" file in project build path.	

index.jsp
---------
<center>
	<h1>
		 Welcome to AWS Class
	</h1>
</center>

web.xml
-------
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns="http://xmlns.jcp.org/xml/ns/javaee" xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd" id="WebApp_ID" version="4.0">
  
  <welcome-file-list>
  	<welcome-file>index.jsp</welcome-file>
  </welcome-file-list>
  
</web-app>

step3:
------
	Convert dynamic project to war file.

step4:
------
	Login to AWS account.
	
step5:
-----
	Goto "IAM" service and create a role.

step6:
------
	Goto "Elastic BeanStalk" and Deploy Application.


step7:
------
	Delete the application.


step8:
-------
	Later Terminate the environment.
	


Amazon S3
============
Amazon Simple Storage Service (Amazon S3) is an object storage service provided by Amazon Web Services (AWS) that allows users to store and retrieve any amount of data from anywhere on the web.

In S3 service we need to create a bucket to upload or download a file.


Steps to upload the files in a S3 storage
-----------------------------------------
step1:
------
	Keep project war file ready.


step2:
------
	Goto S3 service and create a bucket.

step3:
------
	Upload the war to S3 bucket.

step4:
------	
	Delete the files from bucket.
	
step5:
------
	Delete the bucket.
