iii) return stmt 
================
It is used to exit from methods.

It contains optional value.

syntax:
------
		optional 
		  |
	return <value>;

ex:
----

import java.util.Scanner;
class Test 
{
	public static void main(String[] args) 
	{
		Scanner sc = new Scanner(System.in);
		System.out.println("Enter error status code : ");
		int code = sc.nextInt();
		
		if(code==200)
			System.out.println("OK");
		else if(code==404)
			System.out.println("Client Side Error");
		else if(code==500)
			System.out.println("Server Side Error");
		else
			return;
	}
}
