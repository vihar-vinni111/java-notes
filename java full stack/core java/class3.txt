Flavours in Java 
================
We have three flavours in java.

				Java
	|-------------------------|----------------------|
	JSE/J2SE		JEE/J2EE		JME/J2ME
(Java Standard Edition)	 (Java Enterprise Edition)  (Java Micro Edition)

> Desktop App 		> Enterprise App

			> N-tier App 

> Standlone App	
---------------
A normal java program which contains main method is called standalone application.

ex:
	class Test 
	{
		public static void main(String[] args)
		{
		
		}
	}

> Desktop App 
-------------
It is a software application specially designed to perform perticular task.
ex:
	Control panel
	Recycle Bin 
	VLC media player 
	and etc.

> Two-tier App
--------------
Having more then one tier is called two tier application.

> Distributed App 
----------------
Diagram : class3.3

In client/server architecture if multiple clients sending the request to main server then main server will distribute those request to it's parallel servers to reduce the burdun of main server such type of application is called distributed application.


> Enterprise App
----------------
An application which deals with large business complex logic with the help of middleware services is called enterprise application.

Here middleware services means authentication, autherization, maleware production, security and etc.

ex:
	Zoom Meeting 
	Skype 
	Online shopping website 
	and etc.

> ERP App
=========
ERP stands for Enterprise Resource Planning.

It is a centralized software system that helps a company to manage core processes or businesses including finance, human resources, and supply chain management.

> N-tier App 
-----------
Having more then two tiers is called N-tier application.
