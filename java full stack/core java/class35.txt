Q) Write a java program to find out number of digits, sum of digits and check that number 
is even or odd?

Input:
	NEX123

Output:
	No of digits : 3
	Sum of digits : 6
	It is even number 


class Test 
{
	public static void main(String[] args) 
	{
		String str = "NEX123";
		
		String newStr = str.replaceAll("[^0-9]","");
		
		System.out.println("Number of digits : "+newStr.length());
		
		int sum = 0;
		for(char ch : newStr.toCharArray())
		{
			int n = Character.getNumericValue(ch);
			sum += n;
		}
		System.out.println("Sum of digits : "+sum);
		
		System.out.println((sum%2==0)?"It is even number":"It is odd number");
	}
}

Q) Write a java program to display each word starting letter in uppercase?

input:
	this is java class
output:
	This Is Java Class 


class Test 
{
	public static void main(String[] args) 
	{
		String str = "this is java class";
		String[] sarr = str.split(" ");
		
		String result = "";
		for(String s : sarr)
		{
			String word1 = s.substring(0,1).toUpperCase();
			String word2 = s.substring(1);
			result += word1+word2;
			result += " ";
		}
		str = result.trim();
		System.out.println(str);
	}
}

Q) Write a java program to display highest int number from given string?

Input:
	1kg apple for 100 rupees and 2kg mangoes for 200 rupees

Output:
	200


class Test 
{
	public static void main(String[] args) 
	{
		String str = "1kg apple for 100 rupees and 2kg mangoes for 200 rupees";
		String[] sarr = str.split("\\D+");
		int max = Integer.MIN_VALUE;
		
		for(String s : sarr)
		{
			int n = Integer.parseInt(s);
			if(n>max)
			{
				max = n;
			}
		}
		System.out.println(max);
	}
}


Q) John has purchased a new laptop for his office work. His child started to frame word using alphabets. John wants to write a program to find out the longest word created by his child.

Input:
	cat apple elephant ball 		
			
Output:
	elephant 


class Test 
{
	public static void main(String[] args) 
	{
		String str = "cat apple elephant ball";
		String[] sarr = str.split(" ");
		
		String word = sarr[0];
		int cnt = sarr[0].length();
		
		for(String s : sarr)
		{
			if(s.length() > cnt)
			{
				cnt = s.length();
				word = s;
			}
		}
		System.out.println(word);		
	}
}

class Test 
{
	public static void main(String[] args) 
	{
		String str = "hello";

{

	{
		String str = "racar is madam for students";
