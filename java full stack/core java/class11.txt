Main method 
===========
Our program contains main method or not. Either it is properly declared or not. It is not a responsibility of a compiler to check. It is a duty of a JVM to check for main method always at runtime. If JVM won't find main method then it will throw one runtime error called main method not found. 

JVM always looks for main method with following signature.

signature:
---------
	public static void main(String[] args)

Before Java 21, We can perform following changes in main method.

1) Order of modifiers is not important incase of public static we can declare static 
   public also.
   ex:
	static public void main(String[] args)

2) We can declare String[] in following acceptable formats.
   ex:
	public static void main(String[] args)
	public static void main(String []args)
	public static void main(String args[])

3) We can replace args with any java valid identifier.
   ex:
	public static void main(String[] raisetech)

4) We can change String[] with var-arg parameter.
   ex:
	public static void main(String... args)

5) Main method will accept following modifiers.
   ex
	synchronized 
	strictfp (deprecated from Java 17) 	
	final 

Since Java 21 , we can perform following changes in main method.

1) public modifier is optional.
   ex:
	static void main(String[] args)

2) We can declare instance main method.
   ex:
	void main(String[] args) 

3) String[] is optional to declare.
   ex:
	void main() 
	
Q) Explain main method in java?

public 
-----
	JVM wants to call main method from anywhere.
static
------
	JVM wants to call main method without using object reference.
void 
-----
	Main method does not return anything to JVM.
main
-----
	It is a identifier given to a main method.

String[] args 
-------------
	It is a command line arguments.


Command Line Arguments 
======================
Arguments which are passing through command prompt such type of arguments are called 
command line arguments.
ex:
	cmd> java   -version 
	gitbash> git  status
	$> mkdir myfolder 

In command line arguments we need to pass our input values at runtime command.

ex:
	javac    Test.java 

	java     Test  101  Alan  M   1000.0
			|    |    |     |______ args[3]
			|    |    |____________ args[2]
			|    |_________________ args[1]
			|______________________ args[0]

ex:
---
class Test
{
	void main(String[] args)
	{
		System.out.println(args[0]);
		System.out.println(args[1]);
		System.out.println(args[2]);
		System.out.println(args[3]);	
	}
}

Here args.length returns size of command line arguments.

ex:
---
class Test
{
	void main(String[] args)
	{
		for(int i=0;i<args.length;i++)
		{
			System.out.println(args[i]);
		}	
	}
}
