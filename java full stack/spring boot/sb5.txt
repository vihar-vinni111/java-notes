Spring Boot Thymeleaf
=====================
Spring boot thymeleaf is a java template engine to render HTML pages. It allows us to create  web pages that contains dynamic content coming from backend. It acts like a view layer in MVC application.


Project Structure 
-----------------
Thymeleaf1
|

	|

		|
		|---Thymeleaf1Application.java
	
	|---com.rt.www.controller
		|
		|---WebController.java

|---src/main/resources
	|
	|---application.properties 
	|
	|---static
		|
		|-----css (custom folder)
			|
			|---mystyles.css
	|---templates
		|
		|---index.html 
|
|---src/test/java

|---pom.xml

Variable Expression 
===================
A variable expression in a spring boot thymeleaf allows us to access the data from application context (Spring Model) and bind it to the HTML templates.

syntax:
-------
	${....}

package com.rt.www.controller;

import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.RequestMapping;

public class WebController 
{

Selection Expression 
====================
In Spring Boot Thymeleaf, a selection expression (syntax: *{...}) is used to evaluate expressions relative to a "previously selected" object, rather than the entire template context.
ex:
	*{....}

Message Expression 
==================
In Spring Boot, a Thymeleaf message expression is used to retrieve locale-specific text from external properties files, enabling internationalization (i18n) and central management of user-facing messages. 
ex:
	#{...}
