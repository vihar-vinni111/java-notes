JSP to Java Bean Communication 
==============================
JSP to java bean communication is possible by using following tags.

1) <jsp:useBean>
----------------
	It is used to create and locate bean class object.

2) <jsp:setProperty>
------------------
	It is used to set the values to bean object and calls setter methods.

3) <jsp:getProperty>
---------------------
	It is used to get the values from bean object and calls getter methods.

Note:
----
All the above tags are independen tags.

MVC in JSP 
==========
MVC stands for Model View Controller.

MVC is a design pattern which seperates business logic, persistence logic and data.

It is highly recommanded to use MVC design pattern to develop web applications.

Controller acts like a interface between Model and View.

Controller is used to intercept all incoming requests.

Model contains business logic and some times it contains data.

View represent presentation i.e UI(User Interface).

LoginSrv.java
-------------
package com.rt.www;

import java.io.IOException;
import java.io.PrintWriter;

import javax.servlet.RequestDispatcher;
import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

@WebServlet(urlPatterns = "/test", name="LoginSrv", loadOnStartup = 1)
public class LoginSrv extends HttpServlet
{
	protected void doPost(HttpServletRequest req,HttpServletResponse res)throws ServletException,IOException
	{
		PrintWriter pw = res.getWriter();
		res.setContentType("text/html");
	
		//reading form data 
		String uname = req.getParameter("username");
		String pwd = req.getParameter("password");
		
		LoginBean lb = new LoginBean();
		lb.setUsername(uname);
		lb.setPassword(pwd);
		
		//add bean object to request
		req.setAttribute("bean", lb);
		
		if(pwd.equals("admin"))
		{
			RequestDispatcher rd = req.getRequestDispatcher("view.jsp");
			rd.forward(req, res);
		}
		else
		{
			RequestDispatcher rd = req.getRequestDispatcher("error.jsp");
			rd.forward(req, res);
		}
		pw.close();
	}
}
