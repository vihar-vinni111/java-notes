update command 
==============
It is used to modify existing data that is present in database.

syntax:
-------
	update <table> set <column_name>=value where condition; 
ex:
	update student set sname='rani' where sno=101;
	update student set sname='alan',sadd='usa' where sno=102;
	update student set sadd='delhi' where sname='ravi';

Note:
-----
	If we won't use where clause then all rows will be updated.
	ex:
		update student set sno=101;
		update student set sname='raja';
		update student set sadd='hyd';


delete command 
==============
It is used to delete the rows from database table.

syntax:
-------
	delete from <table_name> where condition;
ex:
	delete from student where sno=105;
	delete from student where sname='raja';
	delete from student where sadd='vizag';
Note:
-----
	If we won't use where clause then all rows will be deleted.
	ex:
		delete from student;
		delete from emp;
		delete from dept;

Logical Operators 
=================
It is used to declare multiple conditions in where clause.

We have three types of logical operators.

1) AND 

2) OR 

3) NOT 

1) AND 
-------
It returns the rows if both conditions are true.
Here conditions must be from same row.
ex:
	select * from emp where eid=201 and ename='Alan';
	select * from emp where eid=201 and ename='Ana';  --  no rows selected
	select * from emp where eid=209 and ename='Alan'; --  no rows selected 
	select * from emp where eid=201 and ename='Mark'; --  no rows selected 

2) OR
-----
It returns the rows if any one condition is true.
Here conditions can be from any row.
ex:
	select * from emp where eid=201 OR ename='Alan'; -- 1 row selected
	select * from emp where eid=201 OR ename='Ana';  -- 1 row selected
	select * from emp where eid=209 OR ename='Alan'; -- 1 row selected 
	select * from emp where eid=201 OR ename='Mark'; -- 2 rows selected


3) NOT 
------
It returns the rows except the condition.
A '<>' denoted as NOT operator.

ex:
	select * from emp where NOT eid=201;
	select * from emp where  eid<>201;

	select * from emp where NOT ename='Mark';
	select * from emp where ename<>'Mark';


Between operator 
===============
It returns the rows those who are matching in the range of values.

In between operator we need to declare first lower limit then higher limit.

Between operator works on numbers.

ex:
	select * from emp where eid between 201 and 206;

	select * from student where sno between 101 and 104;

	select * from emp where esal between 15000 and 30000;

IN operator 
==========
It is a replacement of OR operator.
It returns the rows those who are matching in the list of values.

ex:
	select * from emp where eid IN (201,202,209);
	select * from emp where ename IN ('Alan','Mark','Ana');

------------------
Q) Write a query to display employees information those who are working in 10,20 and 30
   department?

	select * from emp where deptno IN (10,20,30);
	or 
	select * from emp where deptno=10 OR deptno=20 OR deptno=30;
	or 
	select * from emp where deptno between 10 and 30;


Q) Write a query to dispaly employees information whose salary is greater then 15000 and less then 40000?

	select * from emp where esal>15000 and esal<40000;


Q) Write a query to terminate all the employees those who are working in 10 and 30 department?

	delete from emp where deptno IN (10,30);	


Q) Write a query to increment salary by 100 whose employee name is Alan and Mark?

	update emp set esal = esal + 1000 where ename IN ('Alan','Mark');


Pattern Maching operators 
=========================
It is used to select letters from database table.

We have two types of pattern matching operators.

1) Percentage(%)

2) Underscore(_)

1) Percentage(%)
----------------
Q) Write a query to display employees information whose name starts with 'A' letter?

	select * from emp where ename like 'A%';


Q) Write a query to display employees information whose name ends with 'n' letter?

	select * from emp where ename like '%n';


Q) Write a query to display employees information whose name contains 'l' as middle letter?

	select * from emp where ename like '%l%';
