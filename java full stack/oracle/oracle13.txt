PL/SQL 
======
PL/SQL stands for Procedural language extensions to SQL.

It gives following features.

1) We can achieve programming features like variables, control statements , loops and etc.

2) It reduces network traffic.

3) It allows us to display custom messages by using the concept of exception handling.

4) We can perform related operations by using the concept of triggers.

5) We can save the source code permanent to database for repeated execution.

PL/SQL Block 
=============
PL/SQL block is also known as PL/SQL program.

syntax:
-------
	DECLARE 
	-
	-  -- declaration section 
	-
	BEGIN 
	-
	- -- executable section 
	-
	EXCEPTION
	-
	- -- exception section 
	-	
	END;
	/

	Here '/' is used to submit the program in database.

Declaration Section 
------------------
It is used to declare variables, cursors, exceptions and etc.
It is optional section.


Executable Section 
-----------------
It contains lines of code which is used to complete a table.
It contains actual logic.
It is a mandatory section.

Exception Section 
----------------
It contains lines of code which is executed when exception is occured.
It is optional section.

To see the output in PL/SQL we need to execute below command.
ex:
	SET SERVEROUTPUT ON 


Q) Write a PL/SQL program to display Hello World ? 

	BEGIN 
	DBMS_OUTPUT.PUT_LINE('Hello World');
	END;
	/

	Here
	DBMS_OUTPUT is a package name.
	PUT_LINE is a procedure name.
	

Q) Write a PL/SQL program to perform sum of two numbers? 

	DECLARE 
	A number;
	B number;
	C number;
	BEGIN 
	A := 10;
	B := 20;
	C := A+B;
	DBMS_OUTPUT.PUT_LINE(C);
	END;
	/

Declaration and initialization using single line 
----------------------------------------------

	DECLARE 
	A number := 10;
	B number := 20;
	C number := A+B;
	BEGIN 
	DBMS_OUTPUT.PUT_LINE('Sum of two numbers is '||C);
	END;
	/

Using '&' symbol we can read dynamic inputs.

ex:
	DECLARE 
	A number(3);
	B number(3);
	C number(6);
	BEGIN 
	A := &a;
	B := &b;
	C := A+B;
	DBMS_OUTPUT.PUT_LINE('sum of two numbers is = '||C);
	END;
	/

In PL/SQL , DRL operations are allowed.

To perform select operation in PL/SQL we need to use "into" clause.


Q) Write a PL/SQL program to display employee name whose employee id is 202?

	DECLARE 
	L_ename varchar2(10);
	BEGIN 
	select ename into L_ename from emp where eid = 202;
	DBMS_OUTPUT.PUT_LINE(L_ename);
	END;
	/	


Q) Write a PL/SQL program to display employee name, employee salary whose employee id is 204?

	DECLARE 
	L_ename varchar2(10);
	L_esal  NUMBER(8,2);
	BEGIN 
	select ename,esal into L_ename,L_esal from emp where eid = 204;
	DBMS_OUTPUT.PUT_LINE(L_ename||' '||L_esal);
	END;
	/

Q) Write a PL/SQL program to display employee name, employee salary based on employee id?


	DECLARE 
	L_eid number(3);
	L_ename varchar2(10);
	L_esal number(8,2);
	BEGIN 
	L_eid := &id;
	select ename,esal into L_ename,L_esal from emp where eid = L_eid;
	DBMS_OUTPUT.PUT_LINE(L_ename||' '||L_esal);
	END;
	/	

Percentage(%) TYPE Attribute 
============================
It is used to declare a local variable with respect to column type.

syntax:
-------
	<variable_name>  <table_name>.<col_name>%TYPE;


Q) Write a PL/SQL program to display employee name, employee salary based on employee id?


	DECLARE 
	L_eid  emp.eid%TYPE;
	L_ename emp.ename%TYPE;
	L_esal  emp.esal%TYPE;
	BEGIN 
	L_eid := &eid;
	select ename,esal into L_ename,L_esal from emp where eid = L_eid;
	DBMS_OUTPUT.PUT_LINE(L_ename||' '||L_esal);
	END;
	/


Percentage(%) ROWTYPE attribute 
===============================
It is used to a local variables which holds complete row of a column.

syntax:
-------
	<variable>  <table_name>%ROWTYPE;

Rowtype variable we can't print directly.

To print the data from rowtype variable we need to use <variable_name>.<column_name>.


Q) Write a PL/SQL program to display employee information whose employee id is 203?


	DECLARE 
	A emp%ROWTYPE;
	BEGIN 
	select * into A from emp where eid=203;
	DBMS_OUTPUT.PUT_LINE(A.eid||' '||A.ename||' '||A.esal||' '||A.deptno||' '||A.job);
	END;
	/


Q) Write a PL/SQL program to display employee information based on employee id?


	DECLARE 
	A emp%ROWTYPE;

	BEGIN 
	L_eid := &eid;
	select * into A from emp where eid=L_eid;

	END;
	/
