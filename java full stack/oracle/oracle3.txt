select command 
==============
It is used to select the records/rows from database table.

syntax:
------
	select * from <table_name>;
ex:
	select * from student;
	select * from dept;
	select * from emp;

	Here '*' means all rows and columns.

Projection 
----------
A process of selecting specific columns from database table is called projection.
ex:
	select sno,sname,sadd from student;
	select sno,sname from student;
	select sname from student;

Arithmetic operation 
--------------------
In select command we can perform arithmetic operations.
ex:
	select sno-100,sname,sadd from student;
	select sno+100,sname,sadd from student;

Column Alias 
------------
A userdefined name given to a column is called column alias.
A column alias is temperory.
ex:
	select sno-100 as sno,sname,sadd from student;
	select sno-100 sno,sname,sadd from student;
	select sno as roll_no,
		sname as first_name,
			sadd as city
				 from student;

Where clause 
=============
It is used to select specific rows/records from database table.

syntax:
-------
	select * from <table_name> where condition;

ex:
---
	select * from student where sno = 101;
	select * from student where sname = 'ravi';
	select * from student where sadd = 'delhi';
